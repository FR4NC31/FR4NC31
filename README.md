# 💫 About Me

Hi, I’m **Francis** 👋  
A **Web & Mobile Full-Stack Developer** focused on building practical applications across frontend, backend, and mobile.

I enjoy building web and mobile applications as standalone products or as connected platforms that share APIs, authentication, backend services, and databases when the project requires it.

I have hands-on industry experience through my internship, where I contributed to a production mobile application using **React Native and Expo**, working on UI implementation, application features, testing builds, and reusable components.

### 🚀 What I Focus On

- Web application development
- Mobile application development
- Full-stack frontend and backend integration
- API & database integration
- Authentication & application logic
- State management & data flow
- Clean and maintainable application architecture

I’m continuously improving my skills by building real projects and learning better ways to design, develop, test, and maintain complete applications.
